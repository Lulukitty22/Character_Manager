# Artificer

Artificer supplies INT-based magic, useful gear and a specialty. Primary target is published2025 Forge of the Artificer, compatible with2024 core. The0–20 checkpoints below use published overview-confirmed features; half-caster tier/slot progression is the continuing foundation. **Exact final prepared counts, plan limits and several detailed costs remain open**; UA tables are not final rules. [Published changes](https://www.dndbeyond.com/posts/2106-whats-new-with-the-artificer-in-eberron-forge-of).

## Mechanics Carol actually gains

The new class makes mundane adventuring gear and replicates magic items; level6 lets it recharge replicated items with slots, drain one for a slot, and swap an item plan. Level11 stores an eligible Artificer spell up to third tier in an item. Later checkpoints expand attunement and survival. None automatically authorizes fifth/sixth-tier Artificer spells before the class unlocks them. [2025 overview](https://www.dndbeyond.com/posts/2106-whats-new-with-the-artificer-in-eberron-forge-of).

## Costs of going all-in

Pure12 stops at third-tier spells; pure14 at fourth; pure17 unlocks fifth. Pure20 remains fifth-tier but has its full crafting/specialty/attunement package. It does not retain Carol's Wizard fifth/sixth-tier access simply because her total level is12. Aetherlock's stored casting can supplement, but not silently replace her eligibility.

Generic Artificer does not mean every gun uses INT to attack. Battle Smith supplies a published magic-weapon INT option; Artillerist supplies ranged training/firearm mechanics; Aetherlock itself could supply an explicit custom option if agreed. Its existing text only states INT damage. [2025 specialty overview](https://www.dndbeyond.com/posts/2109-forge-your-story-with-5-inventive-artificer).

Do not count a legendary granted gun as a replicated item without an agreed source rule. Do not recharge Aetherlock with Magic Item Tinker just because it resembles an Artificer item. Infused Rounds need a deliberate old-infusion/new-plan mapping or an agreed redesign. User permits mechanical changes through frequent short questions; see [weapon issues](../Issues/Aetherlock%20Issues.md) and [three tunes](Aetherlock%20Tunes.md).
