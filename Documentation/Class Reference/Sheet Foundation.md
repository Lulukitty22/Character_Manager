The class tables are progression references, not finished Carol sheets. This file covers the remaining head-to-toe fields and what must be established before drafting her actual sheet. ## HP, checks and defenses

Use first **character** level's maximum die, later fixed averages or recorded rolls, CON modifier per character level, and explicit bonuses. At assumed CON14, fixed-average examples are Wizard12=74HP; Artificer12=87HP; Wizard-start9/Artificer3=77HP, Artificer-start3/Wizard9=78HP. They are illustrative calculations, not Carol's approved HP. Preserve actual rolls if that is the campaign policy.

At historical DEX16, ordinary initiative is+3 before other effects. Speed needs a verified species/custom source; no class table proves30ft. Skills need explicit selected proficiency/expertise sources; do not grant every INT skill because INT22 is high.

Illustrative AC at DEX16: unarmored13; Mage Armor16; half plate17; half plate plus shield19. Shield spell adds5 temporarily when applicable. These are alternative bases/conditional effects, not cumulative permanent equipment bonuses. Armor availability and selected Bladesong restrictions must be checked before offering a mode. Mage Armor does not stack its base formula onto worn armor.

## Fields to populate in the clean draft

| Section | Evidence/decision required |
|---|---|
| Identity |Name/portrait/personality/backstory retained; current species versus historical clone description |
| Ability scores |INT22 confirmed; verify other scores and source of above-normal INT without stacking old planned ASIs |
| Levels |Final class split, total, starting class and published subclasses |
| Saves/skills/tools/languages |Selections and grant sources; proficiency/expertise and situational modifiers |
| HP/AC/initiative/speed |Derivations, current/max/temp HP, equipment, conditional modes, active effects |
| Spells |Class origin, eligible/available/prepared/book state, full definitions, components and concentration |
| Resources |Shared slots, recovery, selected class resources, rest resets; no memory pool |
| Equipment |Ownership, equipped state, attunement, features and bonuses; no orphan manual tags |
| Aetherlock |Six chambers, loaded effects, costs, consumption, attack ability, upgrades and unresolved triggers |
| Faust/constructs |Explicitly approved retained functions; no silent higher-class grants |
| UI and saving |Displayed formulas match actual calculations; spend/rest/level changes and reload preserve state |

Class ASIs/feats are choices, not mandatory INT increases. Ordinary ability-score ceilings do not explain INT22 by themselves; record its approved campaign source. Subclass levels are checkpoints within class levels, never extra levels. Universal spellbooks should be a storage/preparation policy, not a second source of class levels or spells above unlocked tiers.
