# Wizard

Wizard supplies broad high-tier spell access, rituals and knowledge expertise. This is2024 core progression, not Carol's final spell selections or subclass. INT22 gives modifier6; proficiency depends on character total. Starting class affects saves/HP; later Wizard levels do not add starting save proficiencies. [Core rules](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes#Wizard).

## What its mechanics do for Carol

- **Knowledge:** Scholar grants Expertise in one qualifying proficient knowledge skill. With INT6/PB4, a chosen INT skill becomes+14; ordinary proficient skill+10, untrained INT check+6. This is a real knowledge mechanic, not blanket proficiency.
- **Recovery:** one recovery per Long Rest after a Short Rest; budget ceil(WizardLevel/2), no recovered slot above5th. Wizard9 budget5; Wizard11 budget6 still cannot recover a sixth-tier slot.
- **Preparation:** Long Rest swaps; from5, one additional prepared-spell swap on Short Rest. This does not cast or store a spell in equipment.
- **At18:** chosen action-cast first/second-tier spells become repeatable at base tier; reaction Shield is not an eligible2024 Spell Mastery pick.
- **At20:** two selected third-tier spells gain free uses refreshed by Short/Long Rest; ninth-tier spell access already began at17.

These are concise mechanics pointers; final feature text and choices belong in their source/record. [2024 overview](https://www.dndbeyond.com/posts/1753-2024-wizard-vs-2014-wizard-whats-new), [published progression](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes#Wizard).

## What multiclassing costs

Stopping at9 loses new sixth-tier spells, level10 subclass feature, level12 feat and later tiers. Stopping at11 keeps sixth-tier spells but loses the12 feat and later subclass/spell checkpoints. Wizard17/Artificer3 reaches ninth-tier spells but gives up Wizard18 mastery and20 signature spells. A higher shared slot never supplies these missing features. See [tradeoffs](Multiclass%20Tradeoffs.md) and [subclass paths](Subclasses.md).

Standard foundation: d6, INT casting, INT/WIS starting saves, no core armor training. Equipment/Bladesong restrictions must come from selected edition/subclass; no armor/shield bonus is inferred just because Artificer grants training.
