# Class Reference

Updated 2026-10-18. Carol's accepted build is Evoker Wizard 12 / Alchemist Artificer 3. Her Sage background, spell package and three-book arrangement are selected. Start with the [tabletop sheet](../Character%20Sheets/Carol%20Elfnein.md), [Build Sources](Carol%20Build%20Sources.md) and [current status](../Primary/Carol%20Rebuild%20Status.md).

This directory contains both current references and earlier research. Class comparisons and older shortlists are historical alternatives, not instructions to reopen the build. Current work is [campaign architecture](../Systems/Campaigns%20and%20Shared%20Data.md); runtime implementation is deferred.

Default research baseline is 2024 core rules plus named 2025 supplements, with older material explicitly identified. Preserve source confidence. Full rule text belongs in its source; these notes provide calculations, decisions and pointers.
