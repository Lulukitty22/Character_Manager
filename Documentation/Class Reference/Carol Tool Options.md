# Carol Tool Options

2024 published tool menu, using Carol's selected stats and PB+5. **Bonuses are totals for a check with proficiency, not extra bonuses to add again.** They do not improve spells or damage. Basic crafting needs proficiency/materials/time, not an automatic tool check. These are options, not grants or owned kits.

The starred rows preserve the old Crafter menu for reference; Carol no longer chooses Artisan/Crafter tools after switching to Sage. Current native proficiencies are Calligrapher, Tinker, Alchemist and Herbalism, with source confidence in [Build Sources](Carol%20Build%20Sources.md). Manifold may supply artisan forms/proficiency while used. Herbalism is not an artisan tool. This table grants no new proficiency or kit.

## Limits that matter

- ★ marks eligibility for the Crafter feat's three proficiencies, not permission to conjure every listed output. Crafter's fast-made gear comes from a smaller specific table and falls apart next Long Rest. Normal permanent crafting uses normal costs/time.
- Glassblower makes containers/optics, not magical potion effects. Herbalism makes ordinary Potions of Healing under published crafting; Alchemist's experimental elixirs are a separate class feature. Medicine skill does not replace tool proficiency.
- Arcana proficiency already qualifies Carol to scribe scrolls under2024 rules; Calligrapher is not required in addition. Crafting magic items/enchanted ammunition has separate rules; ordinary bullet crafting is not free Spellround manufacture.
- A matching skill and tool can grant Advantage when both apply to the actual check; do not add PB twice or assume every check matches Arcana. Ability can change only when the DM calls for a different applicable check, not automatically INT because Carol is an inventor.

## Leatherworker vs Potter vs Mason
Third Crafter choice remains open after user liked package direction. Leatherworker DEX+8: cases, pouches, backpacks, leather armor, whips. Potter INT+11: jugs/lamps and DC15 identification of contents held in ceramic within24h; overlaps Glassblower niche. Mason STR+4: DC10 chisel symbol/hole; potential skilled stonework via Fabricate, whose craftsmanship restriction requires appropriate artisan proficiency. Spell takes10min, needs raw materials and stone product fits5ft cube; specific architectural projects require DM adjudication. Recommendation Mason for breadth; no automatic structure-damage bonus.
