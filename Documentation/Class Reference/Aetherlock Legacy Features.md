# Aetherlock Legacy Features

Updated 2026-10-18. This is a historical-to-current mapping, not a queue to restore old upgrades. [Aetherlock Engineered Rounds](Aetherlock%20Engineered%20Rounds.md) owns selected mechanics. The [original Discord text](../_OLD/Carol%20Source%20Sheets/DISCORD%20CAROL%20ELFNEIN%20SHEET.txt) and [user-confirmed copy](../_OLD/Carol%20Source%20Sheets/Aetherlock%20Legacy%20-%20User%20Confirmed.md) preserve the original gift. Reposting that source does not reverse later decisions.

The [pre-cleanup review](../_OLD/Carol%20Planning%20Snapshots/2026-10-18%20Before%20Reference%20Cleanup/Aetherlock%20Legacy%20Features.md) preserves earlier recommendations and charge-drive proposals. Those proposals are superseded where the table below states a selection.

| Legacy feature | Selected current relationship |
|---|---|
| Infused Round | Retired. No transferable temporary equipment enchantment or replacement utility recipe. Revised Replicate Magic Item remains a separate class feature. |
| Spellround | Replaced by one actual paid scroll mounted in a Basic Round, preserving donor formulas. Normal applicable attacks, saves and target rules replace the old automatic payload hit. No old class-level preparation cap is restored. |
| Arcane Round | Retained as a distinct enhanced Basic Round: base Piercing +2d6 Force. Recipe is one Basic +5 gp dust +5 gp ink, ten minutes, no slot. Six starting rounds are selected. |
| Overclock | Name and daily PB-use subsystem retired. Separate 12-charge canisters power the selected firing modes. |
| Double Tap | Retired. The old shared-roll/two-payload effect does not return through the new burst rules. |
| Precision Lock | Reworked into Precision Basic/Arcane firing: four charges per projectile, each with Advantage. No old PB pool, +2 spell DC, extra range or one-shot-only restriction. |
| Rapid Cycle | Retired. No additional attack from this feature. Guise retains its own two attack opportunities. |
| Resonant Cylinder | No additional active benefit: selecting a chamber is already part of firing. |
| Higher Capacity Core | No additional active benefit: selected Spellround eligibility already follows actual donor casting, without the old preparation cap. |
| Twin-Linked Cylinder | No separate unlocked bonus. Current Basic/Arcane bursts are 1–3 projectiles per permitted attack; Guise can provide two opportunities. Spellround/HE-FRAG remain one projectile per attack. |
| Living Circuitry | Retired, including old Overclock recovery and free stored-spell discharge without consuming ammunition. |
| Masterwork revolver variant | Retired. The rifle remains Two-Handed; no variant +1 attack bonus or extra attack. |

The old one-handed/Light/3 lb/40–120 ft frame is superseded by Two-Handed/no Light/80–240 ft; current weight remains open. No investment upgrade is active merely because it appears in historical prose.

“Infused with magical energy” may describe Arcane Rounds in lore. It does not create an infusion feature, replica, extra payload or new resource. The chosen Arcane damage/recipe remains unchanged.

Normal Basic/Arcane projectiles use one charge, Precision four, and all stored Spellround/HE-FRAG two. Physical loading is free; canister replacement uses a Bonus Action and its own delay. Consult the current weapon document rather than retaining old action/resource rules from this review.

The current phase is [campaign architecture](../Systems/Campaigns%20and%20Shared%20Data.md). Unusual payloads or genuinely unselected upgrades may be discussed separately; no legacy feature vote is required to resume systems design. Runtime implementation remains deferred.
