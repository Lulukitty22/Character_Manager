## Raising the total

- **9/5 total14:** keeps fifth-tier Wizard access; gains Artificer5, second-tier Artificer spells, additional feat and written gun Spellround cap2; no Magic Item Tinker yet.
- **11/3 total14:** sixth-tier Wizard spells plus specialty; gives up Artificer4–5 compared with9/5.
- **8/6 total14:** item conversion but Wizard max4; fails the current fifth-tier-spell minimum unless an explicit exception is chosen.
- **9/3/2 total14:** adds Font/Metamagic; pool2 and created first-tier slots only. Seventh-tier shared slot does not add seventh-tier spells. INT substitution/prerequisite and Innate source scope need decisions.
- **9/6 total15:** minimum of these ordinary splits retaining fifth-tier Wizard spells and modern Artificer6 conversion.
- **11/6 total17:** sixth-tier Wizard spells plus item conversion; substantial total-level change.

## Level20 endpoints

- **Wizard20:** ninth-tier spells, Scholar, mastery and signatures; no class item-making package.
- **Sorcerer20:** ninth-tier spells,20points and free Metamagic during Innate; no Wizard-only knowledge/ritual/class package or Artificer craft engine.
- **Artificer20:** fifth-tier spells and complete craft/specialty/item engine; no sixth/ninth-tier class casting.
- **17/3:** ninth-tier Wizard spells plus specialty, losing Wizard18–20 package.
- **14/6:** seventh-tier Wizard spells, Wizard14 subclass checkpoint and item conversion; shared ninth-tier slot only for eligible upcasts.
- **11/9:** sixth-tier Wizard spells, Artificer9 specialty; neither class capstone.
- **9/11:** fifth-tier Wizard spells and third-tier Artificer spells with Spell-Storing Item. Shared eighth-tier slots do not create eighth-tier spell access.

These show legal progression packages; handpicking late features without their prerequisite levels is a separate homebrew proposal and must state displaced features/costs. Do not present extra levels and free late abilities as the same decision.
