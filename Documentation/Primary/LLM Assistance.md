# LLM Assistance

Proposed assistant support covers sheet Q&A, spell/import reviews and contextual recommendations. Numeric answers should call deterministic calculations and cite fields/revision. Models may propose structured effects from verified source text; validation and acceptance must happen before those proposals alter gameplay.

- Example: Seraphine DC16 =8+proficiency4+WIS4, using the audited build.
- Extraction needs source spans, rules version, target, formula/magnitude, conditions, duration and stacking; allow unknown values.
- Shield adds5AC temporarily; Mage Armor supplies a different base formula. Merely owning either spell does not activate it.
- Recommendation context: prepared/access/slots, concentration, enemies, position and RP constraints.
- Jev/Julia-1 were proposed by the user; no integration verified. Self-reported confidence or repeated agreement is not measured accuracy.
