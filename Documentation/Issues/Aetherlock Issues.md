# Aetherlock Issues

Current review: [original feature comparison](../Class%20Reference/Aetherlock%20Legacy%20Features.md). The older issue inventory below is historical; selected rules are consolidated in Engineered Rounds.

**Current2026-10-17:** historical issue inventory below; current rules are [Engineered Rounds](../Class%20Reference/Aetherlock%20Engineered%20Rounds.md), for Evoker Wizard12/Alchemist3, total15, aim+11. Every weapon attack may fire a Spellround; donor parameters snapshot at manufacture. Earlier build/bonus/infusion/Overclock text below is not automatically active. Plain tabletop sheet first, Manager later.

Aetherlock is the six-chamber Artificer-attuned rifle/revolver in Carol's historical Discord sheet. It supports prepared Spellrounds, Infused Rounds and force-enhanced ammunition. **User confirms Carol owns it and now permits mechanical changes/rebalancing** because the original designer did not understand the classes. This supersedes the earlier ideally1:1 constraint. Explain changes, ask frequent short questions, and compare three class-matched tunes before selecting rules. It remains a granted custom item, not an automatic class feature. Upgrade status remains pending. Source: [archived Discord sheet](../_OLD/Carol%20Source%20Sheets/DISCORD%20CAROL%20ELFNEIN%20SHEET.txt). No item or character records changed. Proposed comparison: [Aetherlock Tunes](../Class%20Reference/Aetherlock%20Tunes.md).

Latest direction supersedes the specific three tunes: [Engineered Rounds](../Class%20Reference/Aetherlock%20Engineered%20Rounds.md), six unrestricted chambers (six spells possible), consumable physical ammo paid during manufacture, impact and proposed fuse modes. Carol or an actual capable donor caster supplies each spell. Alchemist Artificer3/Wizard9 total12 is the current build. Do not retain the discarded magazine/per-rest caps.
